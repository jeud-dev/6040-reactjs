# Project Overview

## Introduction
โครงการ "ไทยช่วยไทย พลัส (60/40)" เป็นมาตรการกระตุ้นเศรษฐกิจที่ภาครัฐช่วยจ่ายค่าอาหาร เครื่องดื่ม และสินค้าทั่วไป 60% และประชาชนจ่ายเอง 40% โดยให้วงเงินสนับสนุนสูงสุด 1,000 บาท/คน/เดือน (รวมสูงสุด 4,000 บาทตลอดโครงการ) ระยะเวลาใช้งานตั้งแต่วันที่ 1 มิถุนายน – 30 กันยายน 2569เงื่อนไขและสิทธิประโยชน์สำหรับประชาชนสิทธิที่ได้รับ: รัฐบาลสนับสนุนเงิน 60% และผู้รับสิทธิจ่ายเอง 40% โดยสามารถใช้จ่ายได้สูงสุดไม่เกิน 200 บาท/วัน (คิดเป็นยอดใช้จ่ายรวม 500 บาท/วัน)วงเงินจำกัด: รับวงเงินสูงสุด 1,000 บาท/คน/เดือน (หากใช้ไม่หมดในแต่ละเดือน จะถูกตัดยอด ไม่สามารถทบไปเดือนถัดไปได้)

## Purpose
Give calculation result to the app users
1. เหลือสิทธิ x บาท
  - ต้องเติมเงินเท่าไหร่ (=x*0.67) บาท
  - ซื้อสินค้าได้เท่าไหร่ (=x*1.67) บาท
  - ต้องการซื้อ y บาท ต้องจ่ายเองเท่าไหร่ (=y - (x*1.67)) บาท

2. มีเงิน wallet x บาท
  - ได้รับเงินสมทบจากรัฐเท่าไหร่ (=x*1.5) บาท
  - ซื้อสินค้าได้ได้เท่าไหร่ (=x*2.5) บาท
